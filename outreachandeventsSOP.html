Outreach & Events SOP

How every event and the people who attend it get tracked in HubSpot.

1. Definitions

Everyone and everything BG comes into contact with falls into one of these buckets. Get the event setup in Section 2 right, and these numbers take care of themselves.

BG
Initiative		 Which BG initiative a lead belongs to — Franchise Nova, BG Enterprise, Wealth Through Women's Wellbeing, Refuge, Preservation Home & Land, Equipped, Proximate Leaders, or Capital Consortium. Set on every Contact the moment they come in.
Direct Participants
(Count)		 A team member is speaking, presenting, or moderating — a webinar, panel, or talk — where we know a specific number of people were reached, but did not capture individual names or contact info. Entered as one number on the Marketing Event.
Direct Participants
(Confirmed)		 We captured a name + email — through registration, a check-in form, a QR code scan, or a list we imported. This is not a typed-in number: it's everyone marked Attended on the Marketing Event.
Indirect
Participants		 People present at an event we had a presence at, but who we can't confirm any direct engagement with — the rest of a conference floor, a room's total headcount beyond who we actually spoke with. Entered as one number on the Marketing Event, separate from Direct Count.
Capital
Consortium		 Banks and capital partners in our referral network for candidate capital access. Tracked as Contacts with BG Initiative set to Capital Consortium, plus a status — not counted alongside participant metrics. Capital Consortium status detail lives in the Reporting & Pipeline SOP.
No aggregate number: if we had no formal presence at an event — attending as a guest, wandering a conference floor with no booth or speaking role — there's no total to log, so nothing goes in Direct Participants (Count) or Indirect Participants.
But individual contacts still count. Anyone you personally engaged with and got info from — business cards, contact info written down — is a Direct Participant (Confirmed). To capture them properly, put them in a spreadsheet with Name, Email, Phone Number, and BG Initiative (the initiative for the event they attended), then import them as Attended on that specific Marketing Event. That's what puts them on the record — otherwise the connection is lost.
Registered ≠ attended: registering alone doesn't make someone a Direct Participant. Only people marked Attended on the Marketing Event count toward Direct Participants (Confirmed) — registrants who never show up stay at Registered, which automatically excludes them from that number while still keeping them as a real Contact you can follow up with.

2. Every event starts here — create the Marketing Event

Every single event gets a Marketing Event record — whether we host it, someone else hosts it, or we're just attending. No exceptions. This is the one place all event data lives.

1
Create the Marketing Event and name it using this exact format every time: EVENT NAME - DATE. Consistent naming is what makes events findable and reportable later.
2
Fill in every field:
  • Description — what the event is, and anything worth knowing at a glance
  • Organizer — who's running it (us or the host organization)
  • Event Type — see the list below
  • Start Date and End Date
  • Partnered Event — Yes or No
  • Partner Name(s) — leave blank if Partnered Event is No
Event Type — select from the dropdown: Conference · Webinar · Workshop or Reception · Speaking Engagement · Capital Consortium Event · BG Participation

3. Capturing participants — four paths

Every event has the Marketing Event record from Section 2. What happens next depends on how participant data reaches us.

PathWhen this applies
A. We handle registrationWe're hosting, or otherwise running sign-ups ourselves.
B. Someone else hosts, we get a listWe didn't run registration but received names afterward.
C. Count onlyWe only know a total number — no names.
D. BG ParticipationSomeone from BG attended or participated in someone else's event. No registration involved.

Path A — We handle registration

1
Create an event landing page. This is where people will register.
2
Clone the event registration form and change the form title to Event Name - Date (Registration).
3
Customize the form however you need before saving — add photos, add fields for anything specific you want to capture from registrants, adjust the copy. The form is yours to shape per event; just don't remove the hidden BG Initiative field, and make sure it's set to this event's initiative.
4
Embed the registration form on the landing page so registrations are captured.

Path B — Someone else hosts, we get a list

1
Verify what kind of list you've been given. Ask whoever provided it: is this a registration list or an attendance list? They're not the same, and importing one as the other will throw off every number downstream. If they can give you both, ask for both — that's the ideal.
2
Prepare the spreadsheet before importing. Add a column called BG Initiative and type the correct initiative for every row. It must be spelled exactly as HubSpot has it — see the list below.
3
Import the list. Open the Marketing Event in HubSpot → scroll down the middle column to Imports → click Import event contacts. During import, select whether these contacts are Registered or Attended.
4
If you have both lists, order matters: upload the registration list first, then the attendance list. If you only have one, just upload that one.
BG Initiative — type exactly one of these: Franchise Nova · BG Enterprise · Wealth Through Women's Wellbeing · Refuge · Preservation Home & Land · Equipped · Proximate Leaders · Capital Consortium

Path C — Count only

1
Open the Marketing Event and fill in the right number. Use Direct Participants (Count) if this was a specific direct-engagement moment (a team member spoke or moderated) with a known reach but no names. Use Indirect Participants if it's a general attendance total with no specific engagement.

Path D — BG Participation

Someone from BG participated in an event someone else ran — a panel, a conference, a convening. It still gets a Marketing Event record, with Event Type = BG Participation. No registration or check-in happens, but there's almost always something to capture afterward.

Set Event Type to BG Participation when creating the Marketing Event. Everything below happens after the event is over.
1
Add Indirect Participants, if you can get a count. If we can find out roughly how many people were in the room or on the call, enter that number on the Marketing Event. If no count is available, leave it blank.
2
Import anyone whose contact info we captured. Business cards, contact info written down, notes with someone's details — put them in a spreadsheet with these columns:
  • Name
  • Email
  • Phone Number — if we have it
  • Notes — what you discussed, so whoever follows up has context instead of starting cold
  • BG Initiative — the initiative this event relates to
Then import the list to the Marketing Event as Attended. These are Direct Participants (Confirmed).
3
Add Direct Participants (Count) for anyone you talked to but didn't get info from. If you had real conversations with 10 people and only came away with contact info for 5, the other 5 go in this number — they were direct engagement, we just can't reach them again.
Worth the few minutes. Business cards that never make it into HubSpot are the single easiest way for a good lead to disappear — and unlike a missed count, there's no way to reconstruct them later.

4. Check-in forms — when you can capture attendance live

Use a check-in form any time you can capture people as they arrive: we're hosting and can check people in, we have a booth people can check in at, or we can post a QR code for people to check themselves in.

1
Clone the check-in form and change the title to Event Name - Date (Check-in).
2
Confirm the hidden BG Initiative field is set to this event's initiative, then save.

5. Workflows

Clone both event workflows for every event that uses forms. This is what connects form submissions to the Marketing Event and starts lead nurturing.

1
Clone the Registration workflow and the Attended workflow. Rename each to Event Name - Date (Registration) and Event Name - Date (Attended).
2
On both workflows:
  • Click Group 1 and change it to this event's matching form
  • Click 1. Add participant to marketing event and change it to this event
3
On the Registration workflow only: click Add to workflow under the "Not met" branch and change it to the correct BG Initiative nurture workflow. This is what puts the lead into the right nurturing sequence — if it's wrong, people get another initiative's emails, and the mistake is silent.
4
Review and turn both on.

6. Promoting the event (optional — when we're hosting)

If we're hosting and want to get the word out, build a Campaign. This is what turns scattered promotion into something you can actually measure.

1
Create a campaign for the event.
2
Add the assets: the Marketing Event, the registration form, and the landing page. That's what lets you see how many people saw the page versus how many actually filled out the form.
3
Add social media ads to the campaign too, if you're running them. That gives you ROI and total campaign spend in one view.

7. Keeping everything in one place — notes & attachments

The Marketing Event is the natural home for everything about that event, not just the numbers. This matters twice: during the event, so anyone who needs something knows where to find it — and later, when you're planning a similar event and want to see what it actually took last time.

Worth adding as notes: the agenda or run of show · event budget · booth location and number · staffing schedule and who's covering what · speaker names and bios · vendor or catering details · shipping and tracking for booth materials · lessons learned afterward
Worth adding as attachments: venue or floor maps · slide decks · marketing materials and one-pagers · sponsor or vendor agreements · signed contracts · photos from the event

8. Closing out the event

1
Bulk import the attendance list, if applicable — only needed if you didn't use a check-in form. Same process as Path B: Marketing Event → Imports → Import event contacts → mark as Attended.
2
Add Direct Participants (Count) if applicable.
3
Add Indirect Participants if applicable.
4
Add takeaway notes. Click Activities → Notes and write down anything worth remembering — what worked, what didn't, standout conversations, whether it's worth doing again.
5
Create a segment for the event. Clone the Event Segment Template, change the event in the template to this event, then save it.
6
Send the Event Thank You email to that segment. Personalize it before sending — reference something specific about the event so it doesn't read like a form letter.
Want to automate the follow-up instead? You can build a post-registration workflow for the event — enroll anyone who attended, send the thank-you, wait two days, send a survey, and so on. Worth doing for larger events or anything you plan to repeat.
